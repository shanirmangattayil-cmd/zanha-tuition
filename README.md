# Padippura Online Tuition — Zanha Zakhariya

Online tuition app: 8th–10th tuition + Spoken Malayalam for kids in India & the Gulf.

## Install on phone
- **Android:** open the app link in Chrome → ⋮ menu → **Install app**.
- **iPhone:** open the link in Safari → Share → **Add to Home Screen**.

Every push to `main` updates the app automatically — the installed app picks up the new version the next time it opens.
